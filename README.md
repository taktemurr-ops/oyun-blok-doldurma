# oyun-blok-doldurma – Blok Doldurma

Tahtadaki şekli, verilen parçaların hepsiyle boşluk kalmadan doldur.
Bölümler tohumla üretilir: şekil rastgele büyütülür ve parçalara bölünür, bu yüzden her bölüm kesin çözülebilir (çözüm testte doğrulanır).
Zorluk arttıkça tahta büyür (5x5 → 9x9), parçalar büyür ve 5. zorluktan sonra parçalar döndürülmüş gelir.

Blok Oyunları merkez uygulamasında (`merkez-blok-oyunlari`) yer alır. Kumar, şans mekaniği veya 18+ içerik yoktur.
